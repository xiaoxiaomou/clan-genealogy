# 族谱树页 · 庄重谱牒视觉升级（设计方向）

> 面向：zupu 族谱平台 · 牟氏族谱入口的族谱树页（`FamilyTreePage.tsx` / `FamilyTreeGraph.tsx`）
> 目标：把现有「竖排题签 + 朱砂印章 + 卷页卡片 + 竖排成员节点」升级为**更庄重、更有谱牒仪式感**的视觉风格，保持中式谱牒气质。
> 约束：**不改变现有功能结构**（族谱树、成员展示、各功能页面逻辑不变）；只调整视觉样式；不新增非必要功能；不破坏现有谱牒设计系统（`pedigree.css` + `components/ui/pedigree`）的基础元素，基于其升级。

---

## 一、风格定位

**母题：册页 + 印堂（谱牒档案的庄重形制）**

把族谱树页的整体视觉从「轻量信息卡片」拉回「可触摸的族谱档案」。形制对标真实谱牒/册页：卷页用双线卷边围合，内容区用宣纸质感承载，关键信息以朱砂印泥红 + 墨青世代色 + 描金（仅装饰）三色锚定，形成「庄重、厚重、有仪式感」的整体气质。

定位口径：
- **庄重**（不是轻浮）：信息密度克制，强调层级与秩序，不堆装饰元素。
- **厚重**（不是现代花哨）：用纸本、卷边、墨色谱线营造「册页」质感，避免半透明玻璃、强渐变等现代 UI 元素。
- **仪式感**（不是普通界面）：引入谱牒特有元素——朱砂姓印、世代色阶条、字辈朱印、版刻藏书行，让页面具备「翻族谱」的档案仪式。

一句话定位：**「可翻开的族谱卷」**——像翻开一部族谱册子，看到的是有序、有印、有沿的宗脉谱系。

## 二、配色方案

**原则：收敛为四色系，朱砂红为唯一信息强调色，其余均为谱牒语义色。**

| 色阶 | 色值 | 用途 | 说明 |
| --- | --- | --- | --- |
| 朱砂印泥红（唯一强调色） | `#A63A2E` | 姓印、字辈小印、始祖根节点边框、按钮、关键标识 | 沿用原 `--pg-red`，跨主题固定，不随主题变化 |
| 墨色（正文/次文字） | `#2A2118` / `#5C4E3D` / `#8A7A64` | 正文、次级文字、极次文字 | 取代原页头的现代 amber/stone 中性色，形成谱牒墨色底 |
| 墨青世代色（世代色阶） | `#43503F` → `#8E9C7E`（深→浅） | 各世代节点顶色条、世代轴 | 取代原 `--muted` 灰阶，体现辈分尊卑（祖代深墨青、末代浅墨青） |
| 宣纸色（纸本底） | 浅色 `#F6EFE2` / `#FBF6E9`；深色 `#16110D` / `#221A14` | 卷页底、卡片底 | 提供纸本质感，替代纯背景色 |
| 描金（仅装饰） | `#B8963F` / `#D9A44E` | 卷边、卷页框、世代轴、藏书行分隔、节点边框 | 仅作装饰线/边框，**不作为信息色**，避免喧宾夺主 |

**主题适配：**
- 浅色主题（`light`）：宣纸底 `#F6EFE2`，墨色正文，淡纸纹理 + 宣纸纹理叠加。
- 深色主题（`dark`）：深宣纸底 `#16110D`，暖墨正文，保留纸质感（降透明、保留描金边框）。
- 墨韵主题（`ink`）：以墨色为底、朱砂为强调，最贴合谱牒庄重气质（可作为默认推荐主题，但**不改变主题系统本身**，仅视觉层适配）。

**与现有系统的关系：** 全部沿用 `pedigree.css` 中的 `--pg-red` / `--pg-serif` 令牌；新增的配色作为**升级层**挂在同一视觉系统下，不替换原有基础元素（如原有的印章、卷页卡片、竖排题签语义保留，仅按庄重方向强化）。

## 三、布局原则

### 3.1 整体结构（仿册页）
```
┌─────────────────────────────────────────┐
│  册页封面（卷页外框）                     │
│   · 朱点眉标（谱牒 · 宗脉）              │
│   · 朱砂姓印（牟）                        │
│   · 竖排题签（家族名 + 卷主题）            │
│   · 卷帙副题（卷数/世代/人数/治世）       │
│   · 册页内操作按钮（展卷等）              │
├─────────────────────────────────────────┤
│  卷页谱系区（谱图卷）                     │
│   · 世代带（世代数 + 世代色阶）           │
│   · 左墨色轴 + 谱线                        │
│   · 族谱树节点（庄重牌位节点）            │
├─────────────────────────────────────────┤
│  版刻藏书行（卷末）                       │
│   · 籍贯 / 世系 / 藏处 / 修记            │
└─────────────────────────────────────────┘
```

布局要点：
- **层级清晰**：封面 → 主内容 → 卷末说明，三段式仿册页结构，信息有「卷」的归属感。
- **竖向庄重**：主内容区居中、适度留白，避免左右裁切，符合谱牒竖排气质。
- **响应式**：移动端收缩宽度与内边距，保持可浏览性（不破坏树图与成员能力）。

### 3.2 谱图区布局（族谱树页核心区）
- **世代带 + 左墨色轴**：顶部一排世代标签（首世/末世），左侧一列墨青色轴，表示辈分层级，体现谱牒「世代有序」的规范。
- **节点定位**：沿用原族谱树页的节点定位逻辑（庄重版用确定性比例定位，保持谱图形态与庄重排布，不引入动态布局计算负担）。
- **节点为「庄重牌位」**：节点从原「信息卡片」升级为带卷页边框、顶色阶条、字辈朱砂标识的牌位形（见关键元素）。
- **谱线为「墨色 + 描金」**：父子谱线用墨青色（主）+ 描金细线（辅），同世代并列节点之间用描金横向分支线，体现谱系延续。

## 四、关键视觉元素

### 4.1 庄重标识层（提升仪式感的核心）

| 元素 | 形制 | 作用 |
| --- | --- | --- |
| **朱砂姓印** | 圆形/方章形，朱红底、白字、轻微旋转、落印动效 | 作为页面「身份」标识，强化族谱档案感（原页头已有姓氏印章，升级为册页级姓印） |
| **朱点眉标** | 朱红小方块 + 字距展开的竖排题签 | 标识「谱牒」属性，庄重起首 |
| **卷帙副题** | 卷数/世代/人数/治世四项 | 赋予页面「卷册」归属，替代原简略页头信息 |
| **世代色阶条** | 节点顶部墨青色阶（深→浅） | 体现辈分尊卑，是谱牒「世系有序」的视觉表达 |
| **字辈朱砂小印** | 节点右上朱红小方章，印字辈首字 | 保留原字辈标识，强化谱牒信息 |
| **版刻藏书行** | 卷末横排的籍贯/世系/藏处/修记 | 模拟谱牒「藏于谱牒」的存档性质，提升整体仪式感 |

### 4.2 谱图元素

| 元素 | 形制 | 作用 |
| --- | --- | --- |
| **册页卷边** | 双线卷边 + 宣纸卡片底 + 描金框 | 整体纸本质感，是「册页」母题的视觉基础 |
| **庄重牌位节点** | 卷页边框 + 顶色阶条 + 姓名/字辈/生卒行 + 辈分标识 | 节点即谱牒上的牌位，庄重且信息清晰 |
| **始祖根节点** | 加粗描金边框 + 深色顶条 + 放大字号 | 突出谱系源头，体现「始祖承脉」的仪式 |
| **墨色 + 描金谱线** | 墨青主色 + 描金细线，父→子垂直线、同世代横向分支线 | 体现谱系延续的秩序感 |
| **宣纸纹理** | 极淡的纸纹叠加层（装饰，不影响内容） | 强化纸本质感，不喧宾夺主 |

### 4.3 动效（庄重版，兼容无动效偏好）

- 入场动效：册页封面/谱图区/藏书行**浮起淡入** + 朱砂姓印**落印**（缩放→归位+轻微旋转），庄重、克制。
- 节点：入场淡入上浮；**悬停微起**（轻微上移 + 加深阴影），体现可交互的庄重感。
- 兼容：完整实现 `prefers-reduced-motion`，关闭动效时不渲染任何动画。

## 五、设计逻辑（为什么这样选）

1. **从「信息卡片」到「谱牒册页」**：族谱的本质是「传承的档案」，视觉应对应「册页/谱牒」的档案形制，而非通用 SaaS 界面。因此把页面整体包进册页卷边、用纸本质感承载，让视觉 immediately 传达「这是族谱」的语义。

2. **用三色锚定庄重感，避免花哨**：谱牒气质的核心是「克制而厚重」。选择朱砂红（身份/强调）、墨青（辈分/层级）、描金（装饰/秩序）三色，取代现代 UI 常见的多色渐变，形成统一的谱牒色系，让视觉聚焦在「庄重」而非「花哨」。

3. **世代色阶承载谱牒核心语义**：辈分是族谱的核心信息之一，用「深→浅的墨青阶」表达世代尊卑，比灰色阶更贴合谱牒「世系有序」的属性，直接强化页面的谱牒意义。

4. **功能结构零改动，只做视觉层升级**：所有节点、连线、分区结构沿用原族谱树页逻辑，仅调整其视觉呈现（样式、布局形态、配色）。这样保证升级不带来任何功能风险，符合「只调整视觉样式」的约束。
